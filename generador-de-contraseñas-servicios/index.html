Ayuda
¿Cómo funciona?
  1. Selecciona el tipo de contraseña que necesitas
  2. Completa los campos requeridos
  3. Presiona "Generar Contraseña"
  4. Copia la contraseña generada
Ejemplos
  • Dispositivo (Router): r0ut3rEMPRESA&routermain&24051530
  • Dispositivo (Server): s3rv3rEMPRESA&server01&24051530
  • Usuario empresa: 4cc3ssEMPRESA&gquintero&of&24051530
  • Usuario admin: s3cur3EMPRESA&esset&24051530
