Generador QR WiFi

Crea códigos QR para compartir tu conexión WiFi fácilmente

Escanea con tu dispositivo para conectarte

¿Cómo funciona?

  1. Introduce el nombre de tu red WiFi (SSID)
  2. Añade la contraseña y selecciona el tipo de seguridad
  3. Genera el código QR con el botón correspondiente
  4. Escanea el código con tu dispositivo para conectarte automáticamente
